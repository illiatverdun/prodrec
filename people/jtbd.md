# Jobs to be done

Кожна робота записана як «Коли [ситуація], я хочу [мотивація], щоб [результат]»,
з персоною і джерелом у `research/research.md` або `people/personas.md`.

## Main job — exactly one

**Коли** минув якийсь час і я не пам'ятаю, як складається цей місяць,
**я хочу** бачити свій поточний стан без того, щоб сідати й рахувати,
**щоб** ухвалювати рішення про роботу й гроші не наосліп.

- Persona: Та, що веде дні в таблиці (primary)
- Source: `research/research.md` → BENCHMARK → Dimension; CONCLUSIONS → рядок «Між подіями стан
  не існує ні в кого»

## MVP core — three jobs

1. **Main job** — стан місяця видно без дії. Matrix evidence: 3 для P1, і колонка COMPETITORS
   каже «ні» — жоден гравець цього не закриває
2. **Related 1** — зафіксувати день одним рухом. Matrix evidence: 3 для P1, COMPETITORS
   «частково» — найближчий, Harvest, робить це через модалку на чотири поля
3. **Related 3** — показати, скільки лишається після податку й комісії. Matrix evidence: 3 для P1
   і 3 для P2, COMPETITORS «частково» — Hnry вміє лише в одній юрисдикції
